# Jazz Funk

## Summary

Jazz Funk is an energetic, expressive commercial dance style combining
modern choreography, musicality, dynamics and stage expression.

## Experience

Groups are available for different ages and skill levels; beginners can
start without previous dance experience.

## Training focus

-   choreography;
-   musicality;
-   movement quality;
-   dynamics;
-   expression;
-   confidence;
-   individual performance style.

## Audience

The style page focuses on children and teenagers, while the current
Amsterdam schedule also lists an 18+ Jazz Funk group.
