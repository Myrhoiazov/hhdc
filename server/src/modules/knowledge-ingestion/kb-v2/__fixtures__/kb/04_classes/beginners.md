# Beginners

## General rule

Previous dance experience is not required to start.

## Approach

The website states that many students are beginners and instructors
adapt exercises to the student's level.

## Style-specific notes

-   High Heels: can start from scratch.
-   Hip Hop: no special dance or physical preparation required for first
    classes.
-   Jazz Funk: beginner-friendly groups are available.
-   Contemporary: beginners are welcome.
-   Street Jazz: previous experience is not required.
-   Kids Dance: children can start from zero.
