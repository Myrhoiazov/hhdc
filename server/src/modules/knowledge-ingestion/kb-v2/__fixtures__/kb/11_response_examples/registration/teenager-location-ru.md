Хочет записаться, но сначала проверить удобство локации.

## Required facts

Retrieve current city address + matching age group/schedule separately.

📍 \[АКТУАЛЬНЫЙ АДРЕС\]

\[ВРЕМЯ\]

Answer the location immediately; add only the relevant group and CTA.
