# LITO DANCE CAMP --- Booking

## Flow

1.  Parent submits an application.
2.  The team contacts the parent.
3.  Details are confirmed.
4.  Payment information for the deposit is sent.
5.  A €450 deposit reserves the place and counts toward the total
    package price.

## Form fields shown

-   parent's name;
-   child's name;
-   child's age;
-   phone;
-   email;
-   WhatsApp / Telegram;
-   city;
-   comment.
